# Archer Arcade — Project Rules

Android archery duel game in Unity (C#). Shoot arrows in an arc, read the wind, land headshots and knock out
your opponent. Play against the computer (campaign + quick duel) or against a friend on the same phone.
Free forever: no ads, no IAP, no paid currency, no analytics, no accounts.
NaveenCodes by Maa Labs™. The game includes "In loving memory of Maa ❤️" (Settings footer + Credits).

## Source of truth
- `Docs/GAME_DESIGN.md`: what the game IS: goals, rules, archers, arrows, AI, modes, economy, badges, audio.
- `Docs/LEVELS.md`: every campaign level (goal, opponent, distance, wind, arena, par, reward).
- `Docs/SCREEN_INVENTORY.md`: every screen/state and what implements it.
- `Docs/DESIGN_TOKENS.md`: every color, font, size, radius, shadow, motion, sound id and haptic id. Do not invent
  values. If a value is missing, ask.
- `Docs/PROGRESS.md`: the checklist. Update it after every task. Nothing is done until it is checked there.
- `Docs/ROADMAP.md`: versions (1.0 → 2.0) and the ideas backlog.
- Designs (how things LOOK): the Claude Design prototype for Archer Arcade (export it into `Design/` when ready).
  If the design and GAME_DESIGN.md disagree on behaviour, GAME_DESIGN.md wins; log it in PROGRESS.md → Decisions log.

## Hard rules
- Free forever: never add ads, purchases, paid currency, energy timers or "pay to skip". Coins are only earned.
- No INTERNET permission until online multiplayer is actually built (ROADMAP 2.0). Everything works offline.
- All characters, names, art, sounds and music are original. Never copy another game's assets or names.
- No dead buttons, placeholder screens or `TODO` in shipped code. Every button has a real action and correct
  Android Back behaviour.
- Family friendly: cartoon hits and "poof" knockouts, no blood or gore.
- Existing saves must never break: save fields are only ever added, with defaults.

## Tech
- Unity **6000.3 LTS**, URP, **landscape** only, **2.5D** (3D toon characters, gameplay on a 2D side plane), Android AAB (IL2CPP, ARM64), package `com.naveencodes.archerarcade`.
- Reference resolution **844 × 390** (landscape), CanvasScaler match 0.5. All sizes in DESIGN_TOKENS are dp at
  this resolution. Safe area: a `SafeArea` component wraps every UI root.
- TextMeshPro for all text. New Input System for touch. Own tween utility (`ArcherArcade.Tweening`), no DOTween.
- Scenes: `Boot`, `Home`, `Match` only. Scenes, prefabs and UI are generated by Editor scripts under
  `Assets/ArcherArcade/Editor/Builders/` (menu **ArcherArcade ▸ Build ▸ …**). Re-run builders instead of
  hand-editing generated assets.
- Frame rate: 60 fps target on mid-range phones; 90/120 fps on high-refresh screens (read the display's max
  mode); "Battery saver (60 fps)" toggle; drop to 60 fps while the phone reports thermal throttling.

## Conventions
- Namespace `ArcherArcade.<Folder>`. One class per file. `PascalCase` types/methods, `_camelCase` private fields,
  `camelCase` locals.
- Asmdefs: `ArcherArcade.Logic` (pure C#), `ArcherArcade.Runtime`, `ArcherArcade.Editor`,
  `ArcherArcade.Tests.EditMode`, `ArcherArcade.Tests.PlayMode`.
- Match logic is deterministic and input-driven: a shot is `(angle, power, arrowType, abilityUsed)`; the same
  inputs + seed always give the same result. This is what makes AI tests, replays and future online play possible.
- Own `Rng` (PCG32), never `UnityEngine.Random` / `System.Random` for anything that affects gameplay or levels.
- All tuning numbers (HP, damage, gravity, wind, AI error, costs, rewards) live in ScriptableObject configs.
  UI shows values from config. Never hard-code a number in UI or logic.
- Pool arrows, particles, damage numbers, coins, confetti. No allocations in per-frame gameplay code.
- UI animations use unscaled time (pause sets `Time.timeScale = 0`; slow-mo uses timeScale too).
- Save: versioned JSON, write to `.tmp`, then replace (keep `.bak`). Save on every important change and on
  `OnApplicationPause(true)` / quit.
- Placeholder sounds: `python Tools/gen_sounds.py` writes `Resources/Audio/Generated/<id>.wav` for every id in
  DESIGN_TOKENS; real files with the same id in `Resources/Audio/Final/` override them.
- Release switches for staged updates live in `Logic/Meta/Features.cs` (same pattern as MindTap).

## Commands (same Unity install as MindTap)
- Unity.exe: `E:\Unity\Editors\6000.3.24f1\Editor\Unity.exe` (C: is nearly full; keep caches on E:).
- Batch (`-batchmode -projectPath <project root>`): `-quit -executeMethod ArcherArcade.EditorTools.Batch.BuildAll`,
  `-executeMethod ArcherArcade.EditorTools.Batch.Capture`, tests `-runTests -testPlatform EditMode|PlayMode`.
- Logic tests without Unity (any OS, .NET 8): `dotnet test Tools/LogicTests/EditMode`.
- Color space: decide in Phase 1 (Gamma if UI translucency must match CSS designs, like MindTap).
